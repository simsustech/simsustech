## Simple Site Generator

> Easily generate a simple but full-featured website.

The Simple Site Generator is a kit for generating a complete, fast website from
Markdown content. It combines a template, a page and SEO contract, and a
verifier that refuses to accept a broken or slow result.

### Features

- Switch between templates with a single configuration option.
- Define your content in Markdown.
- Builds a full-featured, static, Quasar Framework powered website.
- Ships a verifier that checks the SEO surface, byte budgets and Lighthouse
  scores.
- Includes a GitHub workflow that uploads the generated files to your server.
