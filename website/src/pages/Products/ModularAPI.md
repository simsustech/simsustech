# Modular API

> Modular Node.js API with out of the box OpenID Connect authorization.


### Features
- Uses [Vitrify](https://github.com/simsustech/vitrify) as a build tool.
- Comes with a preconfigured Fastify based API server and a Vue (Quasar) based app client.
- Out of the box OpenID Connect authentication.
- Uses [trpc](https://trpc.io) as a typesafe API.
- Integration of OpenID Connect into trpc for easy authorization.
- The modular approach allows you to easily add your own functionality as a Fastify plugin (server) or Vite plugin (client).
