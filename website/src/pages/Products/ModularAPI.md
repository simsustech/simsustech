## Modular API

> Modular Node.js API with out-of-the-box OpenID Connect authorisation.

### Features

- Uses [Vitrify](https://github.com/simsustech/vitrify) as its build tool.
- Comes with a preconfigured Fastify-based API server and a Vue (Quasar) app
  client.
- OpenID Connect authentication out of the box.
- Uses [tRPC](https://trpc.io) for a type-safe API.
- OpenID Connect integrated into tRPC for straightforward authorisation.
- The modular approach makes it easy to add your own functionality as a Fastify
  plugin (server) or a Vite plugin (client).
