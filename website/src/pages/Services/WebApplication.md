## Web applications

At simsustech we specialise in building complete web applications using our own,
self-developed stack.

**Frontend** — Vue.js with Quasar Framework, resulting in fast, responsive and
visually appealing interfaces.

**Backend** — a self-developed Node.js API based on Fastify, for speed and
reliability. Its main features:

- **OpenID Connect (OIDC) authentication** — a streamlined login experience,
  including third-party login with Google, Facebook or Microsoft.
- **Payments and invoicing** — integrated into the web application, either
  built in or through an external API.
- **A type-safe API with tRPC** — communication between the front end and the
  back end is efficient and faultless.
- **PostgreSQL** — safe, fast and type-safe data storage with PostgreSQL and
  Kysely as the query builder. No limitations imposed by an ORM.
- **Server-side rendering** — better search engine optimisation and quicker
  loading times.

## Complete adaptability

The technical details above provide a solid, safe and fast base for your web
application. Specific feature requests can usually be included, as long as they
do not compromise security or reliability. For example:

- Integrating your own or third-party npm packages.
- Communicating with external APIs.
- Theming the application to your liking.
- Integrating a job scheduler (cron).

## Pricing

Every web application is different, so there is no price list. Tell us what you
need and you get a **fixed quote** before any work starts — that quote is the
price, not an estimate.

### What moves the price

- **How many kinds of user** there are, and what each of them may see and do.
- **Integrations.** A payment provider, an accounting package, an existing
  database, a supplier's API — this is where the surprises are, and leaving one
  out is what makes a quote wrong.
- **Migrating data** from the system it replaces, and how clean that data is.
- **Reporting and exports** — dashboards, invoices, CSV or PDF output are their
  own build.
- **Rules you have to follow**: invoicing standards, retention, audit trails.

### What the quote covers

Front end, API, authentication, database design, the integrations above,
automated checks, and the deploy. You own the code, and the handover explains how
to run it — see [how we work](/process).
