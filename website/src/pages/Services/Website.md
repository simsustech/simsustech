# Website

Built on top of [Vue](https://vuejs.org/) and [Quasar Framework](https://quasar.dev), we provide simple but powerful websites for professionals.
Your website can be highly advanced but still lightning quick due to our static site generation (SSG) support:

Advantages of Vue and Quasar Framework:
- The ecosystem is built around creating high performance websites with great accessibility and loading times.
- By using Quasar Framework, your website will never be limited by the functionality of the underlying technology. You can transform your simple one page website to a complete web application.
- Both Vue and Quasar Framework offer excellent long term support.

Advantages of SSG:
- Performance: SSG delivers high performance as the content is pre-built and served directly to users without server processing.
- Scalability: Serving static files is more scalable as it reduces server load and can handle large volumes of traffic seamlessly.
- Security: With no server-side components, the attack surface is minimized, reducing vulnerabilities.
- Cost-Effective: Hosting static files is usually cheaper and requires less server infrastructure.
